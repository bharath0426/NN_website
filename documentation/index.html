Nivaya — Yoga Studio & Fitness HTML Template | Version 1.0.0

Welcome

Thank you for purchasing Nivaya — Yoga Studio & Fitness HTML Template. We are thrilled you chose our template for your project!

Nivaya is a clean, modern, and pixel-perfect Bootstrap 5 template designed specifically for yoga studios, fitness centers, meditation clubs, and wellness retreats. This documentation will guide you through the setup and customization process.

Note: This is a static HTML template, not a WordPress theme. You will need basic knowledge of HTML and CSS to customize it.

Folder Structure

Once you unzip the package, you will see a folder containing the main template files. Here is the structure:

  • nivaya/ (Main Template Folder)
    • css/
      • bootstrap.min.css (Bootstrap 5.3.3)
      • main.css (Main theme styles)
    • js/
      • bootstrap.bundle.min.js
      • main.js (Custom logic)
    • images/ (All template images)
    • index.html (Homepage)
    • about-us.html
    • classes.html
    • ... (Other HTML pages)
  • documentation/ (This documentation)

Installation

To get started with Nivaya, follow these simple steps:

  1. Unzip the downloaded package from ThemeForest.
  2. Navigate to the nivaya/ folder.
  3. Open index.html in your favorite browser to preview the site locally.
  4. To publish, upload the contents of the nivaya/ folder to your web server via FTP/SFTP.

Make sure your server is configured to serve .html files (which most are by default).

Customization

Colors (Global Styles)

Nivaya uses CSS Variables for easy global customization. You can change the entire color scheme by editing the :root variables in css/main.css.

:root {
  --color-primary: #362d27; /* Dark Brown */
  --color-secondary: #f9f5e8; /* Cream */
  --color-text: #3e332b;
  --color-accent: #fffbf0;
  --color-border: #ede8d9;
}

Typography

Template uses Google Fonts. You can change them in the @import section of main.css and update the variables:

--font-display: "Marcellus", serif;
--font-body: "Catamaran", sans-serif;

Images

All images are located in the images/ folder. To replace an image, simply overwrite the existing file with your own using the same filename, or update the <img src="..."> path in the HTML files.

HTML Structure

Nivaya follows a semantic and organized HTML5 structure for better SEO and readability.

<!-- Header -->
<header class="site-header">...</header>

<!-- Main Content -->
<main>
  <!-- Each section has its own class -->
  <section class="hero-section">...</section>
  <section class="about-section">...</section>
</main>

<!-- Footer -->
<footer class="site-footer">...</footer>
